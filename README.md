# -Selenium-Python

Учебный репозиторий с заданиями по автоматизации тестирования на Python.

## О проекте

В репозитории собраны практические задания курса по Selenium WebDriver, PyTest и автоматизации тестирования веб-приложений.

## Используемые технологии

- Python
- Selenium WebDriver
- PyTest
- Git
- GitHub

## Структура проекта

В репозитории находятся учебные задания и автотесты, выполненные в рамках курса.

## Цель

Практика автоматизации тестирования веб-приложений с использованием Python и Selenium.
